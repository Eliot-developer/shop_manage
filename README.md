# مدیریت فروشگاه — نسخه نصب‌شونده (PWA)

این پوشه برای انتشار روی GitHub Pages آماده است.

## انتشار
1. یک Repository در GitHub بساز.
2. فایل‌های این پوشه را در ریشه Repository قرار بده.
3. از Settings → Pages، گزینه Deploy from a branch را انتخاب کن.
4. Branch را روی main و Folder را روی / (root) بگذار.
5. آدرس GitHub Pages را با Chrome روی گوشی باز کن.

## نصب روی اندروید
وقتی سایت با HTTPS و GitHub Pages باز شد، در Chrome گزینه Install app / افزودن به صفحه اصلی را بزن.

نکته:
- فایل اصلی برنامه باید `index.html` باشد.
- `manifest.webmanifest` و `sw.js` باید کنار `index.html` باشند.
- فایل‌های `icon-192.png` و `icon-512.png` هم باید مستقیماً کنار آنها در ریشه Repository قرار بگیرند.
- اطلاعات برنامه فعلی در localStorage مرورگر ذخیره می‌شود؛ پاک شدن داده‌های سایت یا تغییر مرورگر می‌تواند اطلاعات را از بین ببرد. دکمه «پشتیبان‌گیری» داخل برنامه برای خروجی JSON موجود است.
